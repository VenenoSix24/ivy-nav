# 前台编辑

编辑模式下所有改动直接落库，没有「保存」这一步（退出时的提示是「改动已保存」）。

## 写接口

| 接口                                                          | 说明                           |
| ------------------------------------------------------------- | ------------------------------ |
| `POST /api/items`、`PATCH`/`DELETE /api/items/[id]`           | 条目增删改                     |
| `POST /api/items/reorder`                                     | 条目排序（写 `sort_order`）    |
| `POST /api/categories`、`PATCH`/`DELETE /api/categories/[id]` | 分类增删改                     |
| `POST /api/categories/reorder`                                | 分类排序                       |
| `PATCH /api/settings`                                         | 外观与图标偏好的写入           |
| `PATCH /api/tags/[id]`                                        | 标签改名（名字已存在就是合并） |

都要求管理员会话，未登录返回 401（`src/lib/auth/guard.ts`）。请求体用 zod 校验
（`src/lib/portal/schemas.ts`），网址只接受 `http` / `https`。

标签平时随条目的 `tagNames` 一起写，写完顺手清掉已经没人引用的那些；设置页的「标签」一节可以改名
（`PATCH /api/tags/[id]`），改成一个已经存在的名字就是合并过去。

## 条目

拖动排序用 dnd-kit（`DndContext` + `SortableContext`）：鼠标移动 5px 才起拖，触屏长按 200ms 起拖。
拖动时先按新顺序更新本地状态，再发请求，失败回滚。

编辑面板（`item-dialog.tsx`）：

- 网址可以先填，标题会照网页的 `og:site_name` / `<title>` 自动填（`/api/site-meta`），读不到就提示
  手填；标题空着保存时用域名兜底。
- 图标分档：自动 / 图标库 / Emoji / 上传 / 无。图标库那一档再选库、按关键词搜。
- 「自动」档只在打开面板之后新输入的网址上抓一次，同一个网址只抓一次。
- `iconFit` 只在用户动过选择器时才随条目保存，否则保持空值 —— 跟随设置页里的默认，不会因为一次
  保存就把默认值焊死在条目上。
- 标签框输入时会按已有标签给出匹配提示（方向键选、回车用；没选提示时回车就是新建一个）。标签不再
  被任何条目引用时会在保存条目时清掉，不留看不见的残留行。

## 分类

每个分区标题右边有「⋯」（`category-menu.tsx`）：名称与描述、这一组用哪套布局、上移 / 下移 /
移到最前、从首页隐藏、整类隐藏、删除。上移下移按首页上真正看得见的分区换位（跳过中间的空分类），
点了必有变化。

整类隐藏的分类，分区标题旁边会多一枚「整类 Private」角标：里面的条目自身仍是 Public，但匿名
看不到它们。

「整理分类」（`category-organizer.tsx`）是排序入口：分类摊成两列的紧凑格子，拖动排序，隐藏状态
在里面看得见，每行右边的铅笔改名字与描述，底部能直接新建。排序同样写 `sort_order`，走
`/api/categories/reorder`。

没有条目的分类在首页不占分区，所以那个分区的「⋯」点不到它 —— 名字、描述与布局要去「整理分类」里改。
